# レシート家計簿

レシートの写真をアップロードすると、Claude が商品名・金額・日付を読み取り、カテゴリ別に自動分類して集計する家計簿Webアプリです。

## 機能

- レシート画像のアップロード（クリック選択 / ドラッグ&ドロップ）と、Claude API による自動読み取り
- 読み取り結果の確認・修正（店舗名・日付・商品名・金額・カテゴリ）を経て登録
- 商品名・金額・日付の一覧表示（月ごとの絞り込み付き）
- カテゴリ別の円グラフ・月別の棒グラフ（Chart.js）
- 登録データはブラウザのローカルストレージに保存され、リロードしても消えない

## 構成

| 役割 | 技術 |
| --- | --- |
| フロントエンド | React + Vite + Chart.js（react-chartjs-2） |
| バックエンド | Node.js + Express |
| AI | Claude Haiku 4.5（`claude-haiku-4-5`） |

Claude API のキーはバックエンドだけが `.env` から読み込みます。ブラウザにはキーを渡しません。

## セットアップ

```bash
npm install
cp .env.example .env   # .env を開き、ANTHROPIC_API_KEY を設定する
```

## 使い方

開発モード（フロント: http://localhost:5173 / バックエンド: http://localhost:3001）:

```bash
npm run dev
```

本番モード（ビルドしたフロントもバックエンドから配信。http://localhost:3001）:

```bash
npm run build
npm start
```

## カテゴリ

食費 / 外食 / 日用品 / 交通費 / 医療・健康 / 衣服・美容 / 娯楽 / 光熱費・通信 / その他

カテゴリを増減する場合は [shared/categories.js](shared/categories.js) を編集してください（Claude への分類指示と画面の選択肢の両方に反映されます）。グラフ用の色は [src/constants.js](src/constants.js) にあります。

## 注意

- 画像は縦横の長辺 1568px に縮小してから送信します。非常に縦長のレシートは文字が小さくなり、読み取り精度が下がることがあります。その場合は分割して撮影してください。
- 読み取り結果は誤ることがあります。登録前の確認画面で内容を確認してください。
- データはブラウザごとに保存されます。別のブラウザ・端末とは共有されません。
